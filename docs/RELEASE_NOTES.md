小云雀批量工作台 0.3.0，包含自 0.1.0 以来的素材编排与效率改进。

- 页面内添加或替换素材，支持选择文件和拖入文件，无需重新导入整集。新增素材保存在本地，替换后旧文件和已排队任务保留。
- 点击提示词引用高亮对应素材。排序后列出引用变化，可同步编号或核对后保留提示词；未核对的变化和缺失引用会阻止创建新任务。
- 常用参数模板：保存、修改和套用模型、分辨率、画幅与并发数。默认保留各片段时长，也可统一固定时长；应用模板不会开始生成。
- 支持项目删除、列表内素材拖动排序、移除与恢复；删除项目保留原素材、下载视频和导出文件。
- 放宽文件名识别：支持 01_图片1.png；音频2、3、4 按顺序连续绑定为音频1、2、3。
- 保留持久化队列、任务恢复、逐段验收和历史版本导出。Windows x64 免安装包内置 Node.js，默认并发 3。

使用方式：完整解压文件夹，在 API密钥.txt 填写自己的 Key，双击启动工作台.cmd，导入自己的素材。

旧版本升级：先关闭原启动窗口并备份工作台文件夹；在原文件夹中替换程序文件，保留自己的 API密钥.txt、runtime/ 和 outputs/。不要用发布包中的空白 Key 文档覆盖已有 Key。重新启动后，现有项目可继续使用；旧项目可用“整理已选素材顺序”应用新的识别规则，该操作会重置手动顺序。

本地单文件添加上限为图片 50 MB、音频 200 MB、视频 500 MB；供应商接收限制仍按账号与接口规则执行。编辑弹窗中新增文件会立即存入本地素材库，保存片段后采用；取消编辑后仍可从恢复列表采用。

本工具非官方，与小云雀及其所属公司无隶属关系。使用者需自己的 API 权限和额度。37 项自动测试使用本地数据和模拟供应商，不代表全部模型真实效果已验证。请先选一个片段试跑。

随包提供 SHA-256 校验文件及 Node.js 许可证。发布包不包含维护者的密钥、项目、素材或成片。
