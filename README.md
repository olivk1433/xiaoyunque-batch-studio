# 小云雀批量工作台

面向短剧创作者的**非官方、本地运行**的小云雀沉浸式短片批量工具。

把每个片段的提示词、图片和音频整理成文件夹，检查素材引用顺序，批量设置模型与时长，再交给后台队列；生成完成后逐段验收，保留旧版本，只重做需要修改的镜头。

本项目由社区独立开发，与字节跳动、剪映、小云雀无隶属或官方合作关系。使用者需自行持有有效的小云雀 API 权限，并承担生成费用。MIT 许可证仅覆盖本项目代码，不授予供应商服务、模型或素材的使用权。

## 功能

- 整集文件夹导入，自动识别片段编号、时长、画幅和提示词。
- 图片、视频、音频分别编号，预览素材并试听音频。
- 片段列表展开素材面板，拖动排序、前后移动、移除和恢复，自动保存；可批量按文件顺序重新整理。
- 页面内添加或替换素材，拖入文件即可操作，无需重导整集；引用定位、变化核对及可选同步提示词。
- 保存、修改和套用常用参数模板；可保留各片段时长或统一固定时长。
- 删除项目及历史记录，撤回未提交的排队项，保留磁盘上的原素材和视频。
- 全局/勾选片段批量设置，单片段参数覆盖；列表直接调整秒数，支持上下箭头。
- 本地 SQLite 保存任务、参数快照和版本，默认并发 3。
- 上传内容缓存、异步结果查询、下载失败重试、提交结果不明时人工核对。
- 逐段验收、切换历史版本、选择采用版本并按片段编号导出。
- API Key 可通过本地文本文档填写，自动读取；不回传到网页状态或写入数据库。

## 快速使用

### Windows 免安装版

在本仓库的 **Releases** 下载 `xiaoyunque-batch-studio-v版本号-windows-x64.zip`：

1. 解压整个文件夹到可写目录，不能直接在压缩包内运行。
2. 打开 `API密钥.txt`，在空白行填入自己的 Key 并保存。
3. 双击 `启动工作台.cmd`。浏览器会自动打开，保留后台窗口。
4. 点击“导入整集目录”，填写自己电脑上的素材路径。
5. 检查参数和素材，先选一个片段试跑，再批量提交。

免安装版包含 Node.js Windows x64 运行环境，无需另外安装 Node.js 或 npm。面向 Windows 10/11 x64；其他架构未验证。

### 从源码运行

安装 Node.js 24 后，在项目根目录运行：

```sh
npm start
```

无第三方 npm 依赖，不需要 `npm install`。首次启动会从空白示例创建本地 `API密钥.txt`，随后自行填写。Windows 也可双击 `启动工作台.cmd`。

默认地址优先为 `http://127.0.0.1:3280`；端口占用时在 3281–3300 中选择，以窗口显示为准。Linux/macOS 的源码启动可使用 `npm run dev`，然后自行打开显示的地址；Windows 以外系统不在免安装版验证范围内。

## 素材目录

```text
第一集/
├─ 01_15秒_进门/
│  ├─ 视频提示词.txt
│  └─ 素材/
│     ├─ 图片1_人物.png
│     ├─ 图片2_房间.png
│     └─ 音频1_音色.mp3
└─ 02_08秒_对话/
   ├─ 视频提示词.txt
   └─ 素材/
      ├─ 图片1_人物.png
      └─ 音频1_音色.mp3
```

提示词使用 `@图片1`、`@图片2`、`@音频1`。图片、视频、音频各自从 1 连续编号，编号只在当前片段内有效。按文件名里的数字顺序排序（1、2、10），有数字序号的素材排在未编号素材前，同号或无编号时按相对路径自然排序。支持 `01_图片1.png`、`图片2角色.png` 和普通文件名；`音频2、音频3、音频4` 会依次成为 `@音频1、@音频2、@音频3`。文件系统不会保存可依赖的手动摆放顺序，请在导入后的面板里核对最终顺序。

- 支持 `视频提示词.txt`、`提示词.txt`、`prompt.txt`，每片段根目录应只有一个提示词文件。
- 当提示词明确说明图片1为九宫格分镜时，可识别 `九宫格实景分镜.png` 并绑定图片1。
- `未提供音色说明.txt` 完全忽略，不上传、不追加到提示词。
- 素材原件从所选目录只读访问，不自动复制；移动到其他电脑时需自行携带素材并重新导入路径。
- 修改参数默认不改写提示词。可勾选同步提示词开头的时长与画幅；分镜时间轴仍由创作者核对。
- 点击片段下方“调整素材”，同类卡片可拖动排序，也可使用左右按钮；改动自动保存，可移除后从下拉框恢复，不修改原文件。编辑弹窗内也支持拖动，点击“保存片段”后生效。
- 老项目使用“整理已选素材顺序”即可重新采用新识别规则，无需重新导入。该操作会恢复所选片段的全部已导入素材，并覆盖手动排序；提示词保持原文，请核对引用关系。
- 已排队或已提交任务保留创建时的素材快照，后续编排仅用于新任务。
- 右上角“删除项目”会在确认后移除本项目及历史任务、验收和导出记录；原素材、下载视频和导出文件保留。仍在处理或待核对的任务须先处理完；暂停提交不会取消远端任务。

通用示例见 [examples](examples/README.md)，不包含真实人物素材或剧本。

## 页面内素材操作与引用核对

点击“调整素材”后，使用“添加素材”选择文件，或把文件拖入素材区域。拖到某张素材卡片上或点击“替换”，可替换该素材；替换只接受同一类型的文件。新文件保存在工作台 `runtime/media/` 中，不修改原文件，旧文件可从恢复列表重新采用；已排队任务继续使用旧快照。编辑弹窗中添加的文件立即进入本地素材库，采用顺序和提示词在保存片段后生效；取消编辑后文件仍保留，可再次恢复采用。

本地单文件导入上限：图片 50 MB、音频 200 MB、视频 500 MB，一次最多 50 个；供应商实际接收限制仍按账号与接口规则执行。添加多个文件时按文件名数字顺序依次加入同类末尾。

展开“提示词与素材引用”，点击其中的 `@图片`、`@音频`、`@视频`，对应卡片会高亮；编辑提示词时也可点击引用文字定位。缺少素材的引用会标红。

排序或移除导致已使用的引用关系变化时，页面列出旧编号与新编号。在开始新任务前，可选择“同步引用，保持原素材对应”，或自行核对后选择“已核对，保留当前提示词”。同步按素材身份同时替换全部引用，不会串改交换的编号。已移除且仍被引用的素材须先恢复或编辑提示词，不能自动猜测替代对象；即使手动确认，实际缺失的引用仍会阻止生成。

## 常用参数模板

批量设置中点击“保存参数为模板”，填写名称、模型、分辨率、画幅和并发数。固定时长默认留空，应用时保留各片段时长；填写固定时长后仅修改所选片段。选择模板后点击模板旁的“应用到已选”，会更新所选片段参数及整个工作台的并发数，不会开始生成，也不改写提示词。模板可通过“管理所选模板”修改或删除，在本机数据库持久保存；模板不保存 Key、提示词或素材。

## 密钥、任务与数据

`API密钥.txt` 位于工作台根目录，保存后自动读取，重启后仍有效。页面“连接与设置”填写的 Key 只在本次运行中优先使用，可点击“使用文本文档中的 Key”恢复文件配置。

Key 文档以明文保存，不应提交到 Git、贴入 Issue、附在截图或转发给其他人。提交与发布规则见 [SECURITY.md](SECURITY.md)。

```text
API密钥.txt   本地密钥；Git 忽略
runtime/      项目、参数、任务及进度；Git 忽略
runtime/media/ 页面内添加的素材；Git 忽略
outputs/      视频与采用版本导出；Git 忽略
reports/      可选预检报告；Git 忽略
```

关闭网页后后台仍运行；关闭启动窗口或关机则停止本地调度。再次启动后查询已有 `run_id` / `thread_id`。提交结果不明时不会自动重发，需人工核对；不要为恢复进度删除数据库。

“暂停新增提交”不等于取消远端任务。下载失败只重试查询/下载，不重新生成。新版本不会覆盖旧版，导出只包含已通过并采用的版本，当前不自动拼接整集。

## 接口和已知限制

接入目标为 `pippit_video_part_agent` 沉浸式短片接口，不使用营销视频创建入口。适配包含单文件上传、创建 run、按 run/thread 查询以及视频下载。

- 供应商接口、模型权限、价格、素材数量和时长限制可能变化，按账户与最新供应商文档为准。
- 当前适配按所参考文档限制：1080p 仅为 `seedance2.0_vision` 开放；其他模型按实际响应验证。
- 页面模型名是请求模型；结果协议未提供实际采用模型的确认字段。
- 素材引用语法、音色效果、口型、画面连续性和生成质量需先小范围验证并人工验收。
- 安装可选 `ffprobe` 后可检测实际视频尺寸和时长；没有安装时仍能下载、播放和人工验收，网页可从视频元数据读取尺寸与时长。
- 没有云账户同步、多人权限、统一计费或服务器部署支持；仅监听本机回环地址。

本项目测试使用模拟供应商，不在 CI 中配置真实 Key 或调用付费生成服务。真实供应商联调范围与已知限制保持如实记录，不保证任何模型的生成效果。
